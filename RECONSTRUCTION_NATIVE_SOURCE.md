# SakthiAI Native Reconstruction Contract

## Authority
Recovered Manus W25.1 source is the next engineering authority. The source is a multi-package AI workspace with dedicated web, AI, RAG, agents, creator/video, security, i18n, contracts and UI packages. The current lightweight shell is not the final product authority.

## No-donor UI rule
Do not use DivyaNexus, Kandan, RamaVerse, KirthiVerse or OmSaravanaBhava as visual/layout donors.

## Native design target
A serious next-generation AI operating workspace: evidence-aware research, engineering, agents, automation, creator/media and real runtime/provider states. Avoid a generic SaaS dashboard or decorative fake-AI controls. Every major capability must expose a truthful state such as available, preview, owner-only, provider-required or unavailable.

## Safety/runtime boundaries
Preserve owner approvals, privacy/security controls, tenant boundaries and paid-provider approval gates. Do not enable paid/premium providers or weaken access controls as part of visual reconstruction.

## Required gates before main
- Native W25.1 workspace builds from clean install.
- Real runtime/API integration is explicit for each user-facing AI capability.
- No fake success states or hidden autonomous writes.
- Desktop/tablet/mobile QA.
- Accessibility, keyboard and reduced-motion support.
- Performance budget for workspace-heavy views.
- No cross-site duplication of hero, nav, card grammar, background treatment or motion grammar.
- Existing runtime remains rollback-safe until the new frontend/API hostname separation is proven.

## Release rule
Visual sophistication cannot be used to imply backend capability that is not actually wired and verified.
